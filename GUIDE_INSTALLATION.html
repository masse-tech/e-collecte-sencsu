E-Collecte SEN-CSU — Guide d'installation

Application d'enrôlement des bénéficiaires, hors ligne, pour tablettes, téléphones Android, iPhone, iPad et ordinateurs. Version 1.0.0.

1. Comment ça marche

E-Collecte est une application web installable (PWA). Elle est hébergée à une adresse internet unique ; chaque appareil l'ouvre une première fois avec Internet, l'installe sur l'écran d'accueil, puis fonctionne sans réseau. Les fiches sont enregistrées dans l'appareil et partent automatiquement vers un Google Sheets dès que le réseau revient. Les photos sont rangées dans Google Drive.

ÉlémentRôle
Dossier de l'applicationÀ héberger en https (Netlify, GitHub Pages ou serveur SEN-CSU)
forms/Les 12 formulaires XLSForm (Kobo), utilisés tels quels

2. Héberger l'application

L'adresse doit être en https : sans cela, ni la caméra, ni le GPS, ni l'installation ne fonctionnent.

Option A — Netlify Drop (le plus rapide, gratuit)

  1. Décompressez le ZIP sur votre ordinateur.
  2. Ouvrez https://app.netlify.com/drop et créez un compte gratuit.
  3. Glissez le dossier e-collecte-sencsu dans la page. Netlify donne une adresse du type https://xxxx.netlify.app.
  4. Dans Site configuration > Change site name, choisissez un nom clair, par exemple ecollecte-sencsu-dakar.
  5. Pour publier une mise à jour : onglet Deploys, glissez à nouveau le dossier.

Option B — GitHub Pages

  1. Créez un dépôt GitHub, envoyez-y le contenu du dossier.
  2. Settings > Pages : source « Deploy from a branch », branche main, dossier / (root).
  3. L'adresse sera https://votre-compte.github.io/nom-du-depot/.

Option C — Serveur interne SEN-CSU (Nginx)

server {
  listen 443 ssl;
  server_name ecollecte.sencsu.sn;
  root /var/www/e-collecte-sencsu;
  location = /sw.js { add_header Cache-Control "no-cache"; }
  location /forms/ { add_header Cache-Control "no-cache"; }
  types { application/manifest+json webmanifest; }
}

Un certificat gratuit s'obtient avec Let's Encrypt (certbot --nginx).

3. Créer le serveur de réception (Google Sheets)

  1. Avec le compte Google de la structure, créez un Google Sheets nommé E-Collecte SEN-CSU.
  2. Menu Extensions > Apps Script. Effacez le contenu, collez tout le fichier backend/Code.gs.
  3. Ligne CLE_ACCES : remplacez la valeur par une clé longue de votre choix (ex. SenCSU-Dkr-2026-x7Kq9). Enregistrez.
  4. Choisissez la fonction autoriser dans la liste, cliquez Exécuter, acceptez les autorisations (Drive et Sheets).
  5. Déployer > Nouveau déploiement > type Application Web :
    • Exécuter en tant que : Moi
    • Qui a accès : Tout le monde
  6. Copiez l'URL de l'application Web (elle se termine par /exec).
  7. Partagez le Google Sheets et le dossier Drive « E-Collecte SEN-CSU - Photos » avec les superviseurs (en lecture).
Important. Si vous modifiez Code.gs plus tard, faites Déployer > Gérer les déploiements > modifier > Nouvelle version : l'adresse /exec reste la même et les appareils n'ont rien à changer.

Chaque formulaire a son onglet (ex. « MSD Keur Massar - Adhésion familiale »), et les personnes à charge, élèves et ndongo daara ont un onglet lié par la colonne _parent_uuid. Une fiche renvoyée après correction remplace l'ancienne ligne : pas de doublon.

4. Installer sur chaque appareil

Première ouverture avec Internet obligatoire (téléchargement des formulaires), ensuite plus besoin.

AppareilProcédure
Tablette ou téléphone AndroidOuvrir l'adresse dans Chrome > menu ⋮ > Installer l'application (ou « Ajouter à l'écran d'accueil »). Autoriser la caméra et la position quand l'application le demande.
iPhone / iPadOuvrir l'adresse dans Safari (pas Chrome) > bouton Partager > Sur l'écran d'accueil > Ajouter. Réglages iPhone > Safari : autoriser Caméra et Position.
Ordinateur Windows / MacOuvrir dans Chrome ou Edge > icône d'installation à droite de la barre d'adresse > Installer.

Configuration à faire une fois par appareil

  1. Ouvrir E-Collecte > Réglages.
  2. Mon profil d'agent : prénoms et nom, téléphone, catégorie (pré-remplis dans chaque fiche).
  3. Envoi des données : coller l'adresse /exec et la clé d'accès, puis Tester la connexion.
  4. Formulaires : décocher ceux que l'agent n'utilise pas (ex. un AP de Keur Massar ne garde que MSD Keur Massar).
  5. Sécurité : activer un code à 4 chiffres (recommandé, données personnelles de santé).

5. Déploiement en masse sur les tablettes des AP (MDM)

  • Google Play géré / Android Enterprise (Intune, Scalefusion, Hexnode, Google Admin…) : ajoutez E-Collecte comme application Web avec l'adresse https ; elle apparaît sur toutes les tablettes avec son icône. Les mises à jour se font ensuite sans MDM.
  • APK : sur https://www.pwabuilder.com, saisissez l'adresse > Package for stores > Android. Vous obtenez un APK à pousser par le MDM ou à publier sur le Play Store.
  • App Store iOS : possible via PWABuilder, mais nécessite un compte Apple Developer (99 USD/an).

6. Utilisation au quotidien

  • Formulaires : touchez un formulaire > « Nouvelle fiche ». La fiche s'enregistre à chaque saisie ; on peut fermer et reprendre plus tard (« Reprendre la saisie en cours »).
  • Chaque étape est contrôlée avant de passer à la suivante (champs obligatoires, téléphone, CNI 13 à 17 caractères, montant exact).
  • Le GPS se capture tout seul à l'ouverture ; se mettre à découvert si la précision est mauvaise.
  • Paiement Wave / Orange Money : le QR code et le montant s'affichent selon le moyen choisi.
  • Finaliser la fiche : vérifie toute la fiche, signale un numéro de pièce déjà saisi, puis met la fiche en « À envoyer ».
  • Données : brouillons, fiches à envoyer, fiches envoyées ; recherche ; bouton Envoyer ; Exporter vers Excel (avec ou sans photos en ZIP).
  • Bilan : personnes enrôlées aujourd'hui et sur 7 jours, par formulaire et par agent, montants versés.
Avant de réinitialiser une tablette ou de vider le navigateur : Réglages > Sauvegarde > Créer une sauvegarde, ou vérifier que l'onglet « À envoyer » est vide. Les fiches non envoyées n'existent que dans l'appareil.

7. Modifier ou ajouter un formulaire

  1. Modifiez le fichier XLSForm dans Excel (même format que Kobo : feuilles survey, choices, settings).
  2. Remplacez le fichier dans forms/ (même nom). Pour un nouveau formulaire, ajoutez une ligne dans forms/index.json (id, fichier, titre, structure).
  3. Lancez python3 outils/publier.py dans le dossier, puis republiez (Netlify : glisser le dossier).
  4. Les appareils reçoivent le formulaire à leur prochaine ouverture avec Internet, et un bandeau « Nouvelle version » propose la mise à jour de l'application.

Pour un essai rapide sur un seul appareil : Réglages > Formulaires > Importer un XLSForm (.xlsx).

Pris en charge : text, integer, decimal, date, select_one, select_multiple, image, geopoint, note, calculate, groupes, répétitions (un niveau), relevant, constraint, required, choice_filter, et les fonctions once, now, today, format-date, date, decimal-date-time, if, concat, count, regex, selected, substring-before/after, number, etc.

8. Dépannage

ProblèmeSolution
« Aucun formulaire chargé »Ouvrir l'application une fois avec Internet, ou Réglages > Mettre à jour les formulaires.
Pas de bouton « Installer »Vérifier que l'adresse est en https ; sur iPhone utiliser Safari.
GPS ou caméra refusésRéglages du navigateur > Autorisations du site > autoriser Position et Caméra.
« Clé d'accès incorrecte »La clé dans Réglages doit être identique à CLE_ACCES de Code.gs.
« Serveur : erreur 401/403 »Le déploiement Apps Script doit être « Accès : Tout le monde ».
Fiche « Envoi échoué »Elle est conservée ; elle repart seule au prochain envoi (toutes les 5 minutes avec réseau) ou via le bouton Envoyer.
